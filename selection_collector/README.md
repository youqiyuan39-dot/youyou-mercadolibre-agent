# 悠悠选品采集 0.1.0
本项目自写扩展，未上架 Chrome 商店。仅依赖 Chrome 内置 API，无外部库、无付费服务。

安装：Chrome 扩展管理 → 开发者模式 → 加载已解压扩展 → 选择本文件所在的 selection_collector 文件夹。刷新已登录的智赢新品榜 https://meli.zying.net/#/goods/newlist ，点击扩展图标 → 启用本次采集；工作台“探索新商品”显示连接启用后开始。

权限：storage 只保存启用开关；页面脚本只在 https://meli.zying.net 工作；http://127.0.0.1/* 只用于向本机8790端口领取任务和返回商品表。没有 Cookie、历史、下载、debugger 或全站权限，不读取账号认证数据。

范围：墨西哥、新品榜当前页、最多4轮/10分钟。保持页面打开。遇登录/验证码/控件变化停止，不绕过验证。不执行1688同款付费核价、采集入库、购买、改价、发布。

证据边界：首次版本尚需在实际安装后验证端到端自动运行。辅助浏览器实跑单独标记 ASSISTED_BROWSER，不冒充 EXTENSION 无人值守实跑。相同主图及近似标题只判疑似重复；新刊登不一定是新产品。

停止：工作台停止本轮；扩展暂停采集；或关闭新品榜页面。停止不会删除已保存结果。
