## Tool、MCP和Skill如何服务悠悠

规则类型：PROJECT_CONTRACT；更新日期：2026-10-16

Tool是可执行能力，例如读取SKU或计算利润；模型输出工具名和参数，程序校验并执行，结果回给模型。MCP是连接工具与数据的标准协议，不是模型本身，也不会自动授予权限。Skill是按任务组织的说明与资源，可含脚本，不保证一定可执行。悠悠目前使用注册Python工具，可本地部署，并非每个工具必须改成MCP。成熟Skill适合提炼触发条件、输入输出、步骤和失败停止条件，内容仍需适配本地工具。

## 包装与SKU图片缺项处理（2026-10-16补充）
先核对供应商商品类型和官方类目；节日门帘门幅是装饰挂旗，不是门铰链。嵌套表格的重复品牌文字可恢复为单一明确品牌，不能自动写Generic；货号不能无依据冒充厂家型号。包装重量和折叠装袋后三边按SKU记录，90×180cm这类展开尺寸不能当包装尺寸。文字或图片标注仅对明确对应的SKU有效，只有资料明确说明所有款式同一包装才可自动共用。缺原始三边时需供应商确认或实测；商品编辑页提供批量补齐相同包装空值，需选择SKU并记录依据。公共原图不等于SKU图；可在采集原图区选对应款式并绑定，保存后再自动筛选。每SKU至少3张不同可用图；不足时原图与付费生成图合计，生图仍需人工确认。未知花色映射不能按图片序号猜配；不要把未筛选写成已筛选。
